# Conway's Game of Life

An implementation of Conway's Game of Life with a native desktop GUI built on Bevy.

## Controls

```text
Controls

Space: run/pause
j: step
r: randomize
x: clear
0: reset epoch
+ / -: speed
g: glider
b: blinker
l: LWSS
F3: toggle diagnostics
/: toggle help
Left drag: draw
Right drag: erase
q / Esc: quit
```
