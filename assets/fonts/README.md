IBM Plex Sans Regular is bundled unmodified from the `@ibm/plex-sans` 1.1.0
release (https://github.com/IBM/plex). It is distributed under the SIL Open
Font License 1.1 in [OFL.txt](OFL.txt). The font's original copyright notice
is retained in the font file.

The native UI embeds this asset into the executable so it also works when
launched outside the repository.

Bevy's `default_font` feature also embeds its built-in Fira Mono subset, which
text inputs that set no font fall back to. Fira Mono is under the same licence;
its notice, "Digitized data copyright 2012-2015, The Mozilla Foundation and
Telefonica S.A.", is in the font file, and release downloads repeat it in
`THIRD-PARTY-LICENSES.html`.
